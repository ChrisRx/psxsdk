    Background

    psxsdk started as software for using the Net Yaroze on Linux. When getting started with a Net Yaroze DTL-H3001, the development environment on modern computers, Linux in particular, was badly lacking. After getting a working compiler with mipsel-ecoff-toolchain, the project grew to cover whatever else came out of making Net Yaroze development work on modern machines, and then to writing the programs themselves in Go and running them in an emulator that can check them. The Net Yaroze might not be the ideal PS1 development environment, but the ability to use it should not be lost to time.

    The goals have not changed:

    • Software that is cross-platform and easy to build
    • Modern languages with features that help the software last
    • Libraries and tools that are well-defined and well-documented
    • Source code for everything, always available
