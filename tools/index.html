    Tools

    Tool Purpose
    eco2exe Combine a Net Yaroze program with libps into a bootable PSX-EXE
    elf2exe Write a standalone ELF or ECOFF program as a PSX-EXE
    mips1fix Replace the MIPS II traps LLVM emits with nops so the code runs on an R3000A
    mkpsxiso Build a CD-XA disc image from a directory
    dumpsxiso List or extract a disc image
    mdecenc Encode pictures into an MDEC movie
    hdr2go Generate layout-checked Go bindings from a C header
    psxemu Run the emulator headless, with traces, VRAM dumps and screenshots
    psxplay Run the emulator in a window, booting the built-in OpenBIOS, with the keyboard or a gamepad as the pad
    psxtrace Print and diff instruction traces, compare VRAM dumps
    sioload Upload an executable to a Net Yaroze over the serial cable
    objdump Display ECOFF object files, with disassembly
    ecoff2asm Convert ECOFF objects to GNU as source, for relinking the Net Yaroze library as ELF
    ecoffcmp Check ecoff2asm output against the original objects
    gteprog Write a GTE exercise program as a PSX-EXE, for comparing emulators
